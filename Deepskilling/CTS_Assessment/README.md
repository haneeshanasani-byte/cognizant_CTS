# CTS Deepskilling Assessment

This directory contains the solutions and projects for the **Cognizant CTS Deepskilling Assessment**.

## Modules Covered

1. **Advanced SQL Server** - Queries, Stored Procedures, Indexing, and Optimization.
2. **Engineering Concepts** - Data Structures, Algorithms, and Design Principles.
3. **Entity Framework Core** - Code First, DbContext, Migrations, and LINQ Queries.
4. **WebApi** - RESTful API controllers, Middleware, Authentication, and Routing.
5. **NUnit & Moq** - Unit Testing, Mocking, and Test Assertions.
6. **Microservices** - Service Architecture, API Gateway, and Communication.
